# Facade Pattern Class Samples

Includes:
- Plain Java Order Facade
- Hotel Booking Facade homework answer
- Compensation example
- Spring Boot Booking API
- Spring WebFlux Room Publishing Facade
- Tests
- Postman collection and environment
- Interview answers and lesson mapping

## Run plain Java
```bash
cd facade-pattern-plain-java
mvn clean package
java -jar target/facade-pattern-plain-java-1.0.0.jar
```

## Run Spring Boot
```bash
cd facade-pattern-spring-boot
mvn spring-boot:run
```

## Run WebFlux
```bash
cd facade-pattern-webflux
mvn spring-boot:run
```

## Verification

- All Java source files are formatted across multiple lines.
- The plain Java module is compiled and executed with Java 21 during packaging.
- Spring Boot and WebFlux modules include all referenced application classes and complete Maven POM files.
