### Command turns an operation into an object containing everything needed to perform it. You can then pass that object around or queue it for later execution.
In your AI project, we’ll turn “answer this question” into a command.
```Create command → Add to queue → Execute later```

The command stores:
- The receiver: AnswerService, which performs the work.
- The input: the question to answer.
  Creating the command does not call the model. That happens when execute() is called.
